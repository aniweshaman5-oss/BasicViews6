# BasicViewsex6

## Develop an Android Application Using Basic Views

This project is an Android application developed using basic Android Views.  
The application demonstrates different UI components and user interaction.

## Features

- TextView for displaying text
- EditText for taking user input
- ImageView for displaying an image
- CheckBox for multiple selections
- RadioButton for single selection
- Button for performing an action
- Toast message for displaying feedback

## Technologies Used

- Android Studio
- Java
- XML
- Android SDK

## Android Views Used

| View | Purpose |
|------|---------|
| TextView | Display text |
| EditText | Accept user input |
| ImageView | Display image |
| CheckBox | Select multiple options |
| RadioButton | Select one option |
| Button | Perform an action |
| Toast | Display short messages |

## Project Description

The application demonstrates the implementation of basic Android Views.
Users can enter their information, select options and interact with the
application using different UI components.
